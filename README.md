# 키오스크 프로그램 (Tkinter)

Python 표준 라이브러리 `tkinter`만으로 구현한 무인 주문 키오스크 데모 프로그램입니다.

## 화면 흐름

1. **시작 화면** - 화면 아무 곳이나 터치(클릭)하면 주문이 시작됩니다.
2. **주문 방법 선택** - 매장 식사 / 포장 중 선택합니다.
3. **메뉴 선택** - 카테고리(버거/사이드/음료/디저트) 탭에서 메뉴를 선택해 장바구니에 담고, 우측 패널에서 수량 조절 및 삭제, 총 금액을 확인합니다.
4. **결제** - 결제 수단(신용카드/현금/간편결제)을 선택하면 결제 진행을 시뮬레이션합니다.
5. **주문 완료** - 주문번호를 안내하고, 8초 후 자동으로 시작 화면으로 돌아갑니다.

## 실행 방법

```bash
python main.py
```

- 기본적으로 전체화면(키오스크 모드)으로 실행됩니다.
- `Esc` 키: 전체화면 해제
- `Ctrl+Q`: 프로그램 종료

## 프로젝트 구조

```
main.py                 실행 진입점
kiosk/
  app.py                애플리케이션 컨트롤러(화면 전환)
  data.py                메뉴 데이터
  order.py               장바구니/주문 상태
  screens/
    start.py             시작 화면
    order_type.py        매장/포장 선택 화면
    menu.py              메뉴 선택 + 장바구니 화면
    payment.py           결제 화면
    complete.py           주문 완료 화면
```
